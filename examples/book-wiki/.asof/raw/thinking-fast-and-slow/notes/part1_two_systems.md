# Part I — Two Systems

Daniel Kahneman, *Thinking, Fast and Slow*, chapters 1–9.

## Core distinction

Kahneman introduces **System 1** (fast, automatic, intuitive, effortless) and **System 2** (slow, deliberate, analytical, effortful). The book's central frame: most cognitive work is done by System 1; System 2 is invoked only when System 1 hits a problem it can't resolve.

System 1 is always on. System 2 is lazy — it endorses System 1's outputs unless something forces a closer look.

## Notable mechanisms

- **Cognitive ease**: when stimuli are familiar / clearly displayed, System 1 reports the situation as "fine" and System 2 stays disengaged. The author calls this "WYSIATI" — What You See Is All There Is.
- **Substitution**: System 1 swaps a hard question for an easier one without flagging the switch (e.g. "How happy is your life?" → "How is my mood right now?").
- **Heuristics**: anchoring, availability, representativeness — all System 1 shortcuts that produce systematic bias.
