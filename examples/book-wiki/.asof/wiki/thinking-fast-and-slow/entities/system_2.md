# System 2

Kahneman's **slow, deliberate, analytical, effortful** mode of thinking. Engages only when System 1 hits a problem it can't resolve, or when something forces close attention.

## Characteristics

- Effortful — engaging it consumes cognitive resources, lowers blood glucose, narrows attention.
- "Lazy" — endorses System 1's outputs by default rather than auditing them.
- Limited by working memory and attention.

## When it engages

- Mental arithmetic past two-digit numbers.
- Deliberate planning.
- Rule-based logical reasoning.
- Forced attention (deliberate "slow down" interventions).
