# tinyapp

Tiny demo CLI to showcase the asof codebase-wiki example.

`tinyapp` reads a CSV file and prints summary statistics (mean, median, count) per column. It's a stand-in for a real codebase — the point is to show what an asof wiki looks like for a project with a handful of `.md` docs.

## Project layout

```
README.md           — this file
docs/architecture.md  — high-level design
```
